# Security

Please report a security problem privately: on GitHub, **Security → Report a vulnerability** on this repository
(private vulnerability reporting), rather than in a public issue. You'll get an answer within a few days.

This bot holds a Discord bot token, an SMTP password and the club roster API token (in `.env` on its server, never
in this repository), and a local database of who verified which callsign. See README → Security notes.
